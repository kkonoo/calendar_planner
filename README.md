# 플래너

월간 달력 + 할 일(보드·표) + 반복 일정(음력 포함) + D-day. 빌드 없이 브라우저에서 동작하고, PC·폰에 앱으로 설치할 수 있습니다(PWA).

## 실행

- 배포 주소(GitHub Pages)로 접속 → Google 계정으로 로그인하면 기기 간 동기화
- 로컬 테스트: `tools/serve.ps1` 실행 후 http://localhost:8765 (또는 `index.html` 더블클릭 — 이 경우 로그인·앱 설치는 안 됨)

로그인하지 않으면 데이터는 그 브라우저(localStorage)에만 저장됩니다. **설정 → 백업 파일 저장**으로 가끔 백업해 두세요.

## 사용법

- 상단 **일정 / 보드 / 눈금**: 달력 보기, 할 일 보드, 할 일 표. 보드·눈금 왼쪽 탭에서 카테고리를 고르고, 카테고리 안에 그룹(열)을 만들어 묶기
- 날짜 칸 클릭 → 오른쪽에서 그날 일정 보기·추가. `14:00 랩미팅`처럼 쓰면 시간 자동 인식
- 날짜 칸 더블클릭 → 새 일정 창 (시간은 목록에서 고르거나 `14:15`, `1415`처럼 직접 입력)
- 시간 있음 = 일정 (동그라미 체크), 시간 없음 = 할 일 (네모 체크). 달력에서 바로 체크
- 일정 클릭 → 편집: 끝나는 날(여러 날 막대), 반복(음력 포함), D-day, 체크리스트, 메모
- 반복 일정 편집 시 **이 날만 / 모든 반복** 선택. 반복 일정을 다른 날로 끌면 그날만 이동
- 끌어다 놓기: 일정 → 다른 날짜, 할 일 → 날짜(시간 입력 창), 보드 카드 → 다른 카테고리
- 오른쪽 패널의 ◌ 버튼 → 날짜 칠하기(강조)
- 상단 "2026년 10월" 클릭 → 연·월 선택
- 설정 → 화면: 테마, 글씨 크기

## 불러오기

- **메일의 일정 초대(.ics)**: 파일을 화면에 끌어다 놓거나 설정 → 불러오기. 같은 초대를 다시 불러오면 갱신, 취소 메일이면 삭제
- **DesktopCal**: `tools/export-desktopcal.cmd` 실행 → 설정 → 불러오기에서 `data/desktopcal-export.json` 선택.
  다시 불러오면 이전에 가져온 DesktopCal 항목만 새것으로 바뀜. 글자색 → 카테고리, `[+]` → 완료, 끝나는 날이 있는 '매일' 반복 → 여러 날 일정
- **백업 파일(.json)**: 지금 데이터를 통째로 바꿈

## 파일 구성

```
index.html              화면 구조
css/style.css           디자인 (색은 맨 위 :root 변수)
js/app.js               날짜·반복(음력) 계산, 달력, 편집 창, 설정, 불러오기
js/views.js             보드·눈금 보기 (왼쪽 탭 = 카테고리, 열 = 그룹)
js/sync.js              Google 로그인 + 동기화 (Firebase)
js/firebase-config.js   Firebase 프로젝트 설정값
js/ics.js               .ics 변환
js/desktopcal.js        DesktopCal 변환
js/holidays.js          공휴일 (2026–2027)
firestore.rules         Firestore 보안 규칙 (콘솔에 붙여 넣기)
manifest.webmanifest, sw.js, icons/   앱 설치(PWA)·오프라인
tools/                  DesktopCal 내보내기, 로컬 테스트 서버
```

`data/`(개인 일정)는 `.gitignore`로 저장소에 올리지 않습니다.
